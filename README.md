## 🛡️ Aturan main

1. Jangan pernah kasih seed phrase / private key ke situs mana pun.
2. Verifikasi domain persis sebelum connect wallet (waspada phishing).
3. Satu identitas, satu aktivitas konsisten — multi-akun = pola sybil, kena filter.
